# Image-Led concept test

Generated by `research/tools/image-led-test.mjs`. Phase 2 decision D2 asked for this test before any Image-Led direction is written.

**Concept.** Image-Led: imagery tone (Light/Dark) + one type color + a scrim, with no ground color.

**Criteria, fixed before the first run.** C1: median thumbnail L outside 0.45–0.65 for ≥ 80%. C2: type polarity opposes imagery tone for ≥ 80% of entries where both are known. C3: figure is a single flat color for ≥ 80%.

**Entries.** The 62 reviewed sites whose proposed label is photo-led (family "Photo-led" in `review.md`). Imagery tone is measured from thumbnail pixels; type tone is measured for recorded colors and read from the reviewer's words otherwise.
